# Highway Hope Charity Coding Club website
Responsive static landing page created from the supplied Google Form.

Registration responder URL:
https://docs.google.com/forms/d/1WNLQbox8rDkb12cV-1fk8jrhPD9FMrorfBmTrR4vD4M/viewform

The site reflects the current form fields: enrolment, name, age range 7–10 / 11–15 / 15–18, phone, email, course interest (Python, Scratch & Minecraft, AI Education, Web development), online/onsite instruction and preferred timing.

Upload index.html and styles.css to your hosting. To embed the form directly instead of opening it in a new tab, publish the Google Form and replace the registration buttons with Google's generated Embed/iframe code.
